# Дизайн-решения

## Концепция

Ремонт под ключ в Алматы для людей, которые доверяют дому профессионалам. Тон: спокойная уверенность, "золото на графите", журнальная подача интерьера без украшательства.
Ориентир по уровню: Inspire Interiors (файл `ava.jfif`), но со своими цветами, шрифтами и структурой: 10 блоков из ТЗ, ничего лишнего.

## Палитра (взята из логотипа)

| Роль | Значение | Использование |
|------|----------|---------------|
| Золото | `#FFC700` | кнопки, акценты, фокус; на светлом фоне только как заливка с графитовым текстом |
| Обсидиан | `#0F0F11` | темные секции, текст на золоте |
| Белый / бумага | `#FFFFFF`, `#F8F9FA` | светлые секции |
| Градиент логотипа | `#FBED21` -> `#FAAE3B` | только в знаке, не в интерфейсе |

Контраст проверен скриптом `npm run check:contrast` (текст >= 4.5:1, крупный >= 3:1). Тени слоистые, тонированные под фон, низкой непрозрачности. Фон секций с зерном (SVG-тайл `grain.webp`) и несколькими радиальными градиентами.

## Типографика

- Заголовки: **Playfair Display 500**, курсив для акцентных слов. Тесная трекинг-плотность на крупных размерах (`-0.03em`).
- Текст и интерфейс: **Onest** (кириллица и казахские `Ә Ғ Қ Ң Ө Ұ Ү Һ І` рисованы в самой гарнитуре). Межстрочный 1.7.
- Шрифты подрезаны и подключены локально (`next/font/local`, `font-display: block`), глифы проверены: `docs/font-glyph-check.md`.
- Символ тенге `₸` в заголовках набирается Onest (в Playfair его нет).

## Форма и поверхности

- Радиусы: 12 / 20 / 24 / pill (кнопки), без смешения с острыми углами.
- Уровни глубины: база -> приподнятые карточки -> плавающие элементы (шапка, FAB).
- Анимируются только `transform` и `opacity`, пружинные кривые; `transition: all` нигде нет; `prefers-reduced-motion` уважается.
- Каждый кликабельный элемент: hover, `:focus-visible`, `:active`.

## Мобильная устойчивость (требование клиента)

- `html, body { overflow-x: clip }`, `overscroll-behavior-y: none`: страница не "резинится" и не уезжает вбок.
- Шапка зафиксирована; стеклянный фон включается через IntersectionObserver (без обработчиков scroll).
- Гамбургер справа (три линии, при открытии превращается в X), переключатель RU | KK слева от него.
- `100svh` для hero, `safe-area-inset`, блокировка прокрутки под меню/лайтбоксом.
- Проверено скриптом `npm run check:overflow` на ширинах 360 / 390 / 768 / 1024 / 1440 / 1920 по 10 страницам (60 из 60 без горизонтального переполнения).

## Плавающая кнопка связи

Желтая кнопка с зелеными волнами (цвета WhatsApp): пульсация двумя кольцами и легкая "вибрация" иконки каждые несколько секунд. Раскрывается в WhatsApp и Telegram. Анимация только transform/opacity, отключается при `prefers-reduced-motion`. Подгружается лениво после простоя, чтобы не влиять на LCP.

## Подарок (прайс-лист)

Появляется в трех местах страницы и в диалоге: пункт в меню шапки, плашка в блоке калькулятора (после расчета логично получить прайс), ссылка в финальном блоке; все открывают один диалог. Диалог собирает имя, телефон, язык; без PDF честно сообщает, что прайс пришлет менеджер.

## Фотографии

Конвейер `npm run photos`: Real-ESRGAN x4 (смешивание 75/25 с Lanczos) -> цветокоррекция в Lab (баланс белого по нейтральным пикселям, экспозиция, S-кривая, vibrance, защита светов) -> экспорт AVIF/WebP/JPEG + LQIP. Контрольный отчет: `docs/photo-qa/report.md`. Лучшие кадры: hero (гостиная p06 на десктопе, спальня p04 на телефоне), затем "Работы" и галерея.

## Отступления от ТЗ и ожиданий (честно)

- GSAP, Three.js и другие анимационные библиотеки не подключены: ТЗ запрещает параллакс/видео-фон, а производительность на телефоне важнее. Слайдеры и лайтбокс сделаны на CSS и pointer events. `/impeccable init` в этой среде недоступен как навык.
- Lighthouse локально: Доступность, Best Practices, SEO = 100. Производительность на медленной машине 51-82 (LCP 3.8-5.2 с, CLS 0): Chrome не считает картинку на весь экран LCP-кандидатом, плюс шум локального окружения. Нужен замер PageSpeed Insights после выкладки на Vercel (CDN, HTTP/2, сжатие).
- Для отзывов, площадей, сроков и "до/после" данных нет, поэтому они не выдуманы (см. `open-questions.md`).
