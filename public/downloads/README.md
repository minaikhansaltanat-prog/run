# Подарок: прайс-лист

Положите сюда PDF прайс-листа RUH Construction с именем `ruh-price-list.pdf`
и в `config/site.ts` поставьте `gift.available: true`.

Пока файла нет, форма "Подарок" принимает заявку и менеджер присылает прайс-лист сам
(клиенту показывается честное сообщение, а не битая ссылка).
